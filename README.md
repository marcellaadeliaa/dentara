# DENTARA

**Sistem Informasi Manajemen Klinik Gigi Berbasis Web**

DENTARA merupakan aplikasi berbasis web yang dikembangkan untuk membantu mengelola kegiatan pelayanan dan administrasi klinik gigi dalam satu sistem terintegrasi.

## Fitur Utama

1. Halaman Publik
2. Portal Pasien
3. Front Desk (Resepsionis)
4. EMR Dokter
5. Apotek
6. Kasir
7. Dashboard Manajemen

## Teknologi

- PHP Native
- HTML
- CSS
- JavaScript
- MySQL
- Laragon
- Git & GitHub

## Tujuan

Membantu proses pendaftaran pasien, pengelolaan antrean, pencatatan rekam medis elektronik, pengelolaan resep dan inventaris, serta pembayaran dan laporan klinik.
